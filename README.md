# Portal SBS Web

Página para abrir sites dentro do navegador do Bigscreen (Meta Quest) ou dos óculos Rokid, divididos em duas metades iguais (lado a lado / SBS), para usar o modo 3D lado a lado do aparelho.

Abrir: https://ricardofilhorh-rgb.github.io/portal-sbs/

Sites que bloqueiam ser abertos dentro de outra página não funcionam.
